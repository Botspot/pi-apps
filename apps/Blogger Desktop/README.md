# Blogger Desktop

Accessible Blogger Desktop application for Raspberry Pi OS built with GTK 3 and WebKit2GTK.

## Features
- Optimized for Raspberry Pi OS (ARM64)
- Screen reader friendly interface (Orca integration)
- Lightweight GTK 3 & WebKit2GTK interface for quick Blogger panel management

## Installation

### Method 1: Using .deb Package
Download the latest `.deb` package from the [Releases](https://github.com/teknologvolkanozdemir/blogger-desktop/releases) section and install it:

```bash
sudo apt update
sudo apt install ./blogger-desktop_1.0.0-1_arm64.deb
