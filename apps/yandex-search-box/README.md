# Yandex Search Box (Yandex Arama Kutusu)

[TR]
Raspberry Pi OS ve Linux masaüstleri için Python 3 ve GTK 3 (PyGObject) altyapısıyla geliştirilmiş, %100 Orca ekran okuyucu uyumlu Yandex arama kutusu uygulaması.

### Özellikler
- **%100 Erişilebilir:** Orca ekran okuyucu için tam ATK/AT-SPI etiketleri ve canlı sesli durum bilgilendirmesi (Speech Dispatcher / `spd-say`).
- **Web Entegrasyonu:** Arama terimini girip Enter'a bastığınızda doğrudan varsayılan tarayıcınızda (Firefox) Yandex arama sonuçlarını açar.
- **Klavye Kısayolları:** 
  - `Alt+A`: Arama kutusuna odaklan
  - `Escape`: Pencereyi kapat

---

[EN]
Lightweight Yandex search box utility designed specifically for Raspberry Pi OS and Linux desktops using Python 3 and GTK 3 (PyGObject), with 100% Orca screen reader accessibility compliance.

### Features
- **100% Accessible:** Native ATK/AT-SPI label bindings and live audio status notifications (`spd-say` / Speech Dispatcher) for Orca screen reader users.
- **Web Integration:** Instantly opens Yandex search results in your default browser (Firefox) upon hitting Enter.
- **Keyboard Shortcuts:**
  - `Alt+A`: Focus search input
  - `Escape`: Close window
