# Bing Search Box (v1.0.0)

Bing Search Box, Raspberry Pi OS ve Linux masaüstleri için Python 3 ve GTK 3 altyapısıyla geliştirilmiş, hafif ve %100 Orca ekran okuyucu uyumlu masaüstü Bing arama uygulamasıdır. 

Arama metnini yazıp **Enter** tuşuna veya **Ara** butonuna bastığınızda sonuçlar doğrudan varsayılan web tarayıcınızda açılır.

---

## Hızlı Kurulum

Terminalinizde aşağıdaki tek satırlık komutu çalıştırarak uygulamayı `.deb` paketi olarak anında sisteminize kurabilirsiniz:

```bash
wget -qO- [https://raw.githubusercontent.com/teknologvolkanozdemir/bing-search-box/main/install](https://raw.githubusercontent.com/teknologvolkanozdemir/bing-search-box/main/install) | bash
