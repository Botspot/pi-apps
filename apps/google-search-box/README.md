# google-search-box
 Raspberry Pi OS için hızlı Google arama kutusu masaüstü uygulaması

# Google Search Box (v1.0.0)

Google Search Box, Raspberry Pi OS ve Linux sistemler için Python 3 ve GTK 3 altyapısıyla geliştirilmiş, %100 Orca ekran okuyucu uyumlu masaüstü Google arama uygulamasıdır.

---

## Hızlı Kurulum

Terminalde aşağıdaki komutu çalıştırarak uygulamayı anında sisteminize kurabilirsiniz:

wget -qO- https://raw.githubusercontent.com/teknologvolkanozdemir/google-search-box/main/install | bash

---

## Özellikler

- %100 Erişilebilir: Orca ekran okuyucu için anlık sesli durum bilgilendirmesi (spd-say).
- Masaüstünden Hızlı Arama: Doğrudan arama yapma ve otomatik varsayılan web tarayıcısı (Firefox) entegrasyonu.
- Sistem Dostu: Hafif GTK 3 arayüzü.

# Google Search Box (v1.0.0 - English)

Google Search Box is a lightweight desktop search tool for Raspberry Pi OS built with Python 3 and GTK 3, fully accessible with Orca screen reader support.

---

## Quick Installation

Run the following command in your terminal:

wget -qO- https://raw.githubusercontent.com/teknologvolkanozdemir/google-search-box/main/install | bash
