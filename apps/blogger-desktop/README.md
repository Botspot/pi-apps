# Blogger Desktop (v1.0.0)

Blogger Desktop, Raspberry Pi OS ve Linux sistemler için Python 3, GTK 3 ve WebKit2 kullanılarak geliştirilmiş, %100 Orca ekran okuyucu uyumlu ve klavye imleciyle gezinme (Caret Browsing) destekli masaüstü Blogger yönetim uygulamasıdır.

---

## Hızlı Kurulum

Terminalde aşağıdaki komutu çalıştırarak uygulamayı anında sisteminize kurabilirsiniz:

wget -qO- https://raw.githubusercontent.com/teknologvolkanozdemir/blogger-desktop/main/install | bash

---

## Özellikler

- **%100 Erişilebilir:** Orca ekran okuyucu ve Linux erişilebilirlik standartları ile tam uyum.
- **Caret Browsing:** Dahili klavye imleci ile gezinme desteği.
- **Hafif ve Bağımsız:** GTK 3 ve WebKit2 altyapısıyla minimal sistem kaynağı kullanımı.

# Blogger Desktop (v1.0.0 - English)

Blogger Desktop is a lightweight, 100% accessible desktop manager for Google Blogger developed using Python 3, GTK 3, and WebKit2 with full Orca screen reader and Caret Browsing support.

---

## Quick Installation

Run the following command in your terminal:

wget -qO- https://raw.githubusercontent.com/teknologvolkanozdemir/blogger-desktop/main/install | bash

---

## Features

- **100% Accessible:** Designed with screen reader compatibility (Orca) in mind.
- **Caret Browsing:** Built-in keyboard cursor navigation support.
- **Lightweight:** Low resource consumption powered by GTK 3 and WebKit2.
